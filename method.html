1. 先看清战场：35 分从哪来

408 计算机学科专业基础综合总分 150：数据结构 45、计算机组成原理 45、操作系统 35、计算机网络 25。操作系统不是「小学科」，它的 35 分里有大量稳定计算题，投入产出比很高。

题型大致分值考什么拿分策略
单项选择题约 20 分（约 10 题）概念辨析、状态转换、调度/置换算法、I/O 方式、文件分配概念题不丢，计算题套模板；不会的先排除明显错误项
综合应用题约 15 分（2 题，常见 7+8）PV 同步、死锁/银行家、页表与地址转换、页面置换、磁盘调度、文件索引先写公式和步骤，再算结果；步骤分往往比结果分多

注：每年题型分布略有浮动，以上为近年常见结构，用于安排复习权重，不要当成绝对数字。

近十年高频考点（按出现频率排）

梯队考点常见题型对应章节
第一梯队（几乎每年）进程状态与转换、调度算法计算、PV 同步互斥、死锁/银行家选择 + 大题第 2 章
第一梯队分页地址转换、页表大小、页面置换与缺页率、虚拟内存选择 + 大题第 3 章

第二梯队中断与系统调用、内核态/用户态、I/O 方式、缓冲、SPOOLing选择题为主第 1 章 / 第 5 章
第三梯队（轮换）多级页表、TLB/EAT、分段/段页式、FAT、位示图、SSD选择 + 小计算第 3~5 章
📌 复习权重的结论
第 2 章（进程）和第 3 章（内存）必须吃透，它们贡献了 OS 大题的大部分；第 4 章的计算题性价比最高；第 1、5 章以选择题为主，概念要准但不必钻太深。不要把时间平均分给五章。

2. 三轮规划：每轮只做一件事

第一轮 · 基础6~8 周按 01→05 过一遍教材/网课，理解概念，做章内基础题能用自己的话解释每个机制；五状态、分页、PV、三种文件分配能画出来

3. 零基础第一轮怎么读

🧭 别从「定义」开始背
操作系统是「设计出来的」，不是「发现出来的」。每学一个机制，先问三个问题：它解决什么问题？没有它会怎样？它的代价是什么？比如虚拟内存：解决内存不够；没有它大程序跑不了；代价是缺页与地址转换开销。答出这三问，概念就活了。

推荐顺序

第 1 章（地图）→ 第 2 章（进程，核心）→ 第 3 章（内存，核心）→ 第 4 章（文件）→ 第 5 章（I/O）。不要先啃第 5 章，概念碎且依赖前面。

每节最小闭环

读一段 → 合上书用自己的话复述 → 画一张草图 → 做 2 道题。只读不做 = 假学习；只做不读 = 背题。

4. 六类计算题模板（考场直接套）

模板 1 · 调度：周转与带权周转

画时间轴，按算法规则填每个进程的开始/完成时间。
周转 T = 完成 − 到达；带权 W = T ÷ 服务时间。
求平均：分别求和 ÷ 进程数；注意单位（ms）和保留小数。
⚠️ 常见错
忘记「到达时间」导致周转算成服务时间；RR 忘记新进程在时间片结束时入队；SJF 在「当前时刻」只比较已到达的进程。

模板 2 · 页面置换：缺页次数与缺页率

画表格：列 = 引用串的每一次访问，行 = 每个页框。
逐列填：命中就照抄，缺页就按算法换页；在列头标「命中/缺页」。
缺页率 = 缺页次数 ÷ 总访问次数；OPT 需要看「未来最晚使用」，LRU 看「过去最久未使用」。

模板 3 · 地址转换与页表大小

页内偏移位数 = log₂(页大小)；页号位数 = 逻辑地址位数 − 偏移位数。
页表项数 = 2^页号位数；页表大小 = 项数 × 每项字节数。
物理地址 = 页框号 × 页大小 + 页内偏移；多级页表把页号按「每页可容纳的页表项数」拆位。
📌 多级页表速算
4KB 页、4B 项 → 每页 1024 项（10 位）；32 位地址 → 20 位页号 → 10+10 两级；48 位地址、8B 项 → 每页 512 项（9 位）→ 36 位页号 → 9+9+9+9 四级。

模板 4 · 磁盘调度与存取时间

写出服务顺序（SSTF 每次找最近；SCAN 先同向到端点再反向）。
总移动 = 相邻磁道号差的绝对值之和；注意是否把到端点/返回 0 的行程算入。
存取时间 = 寻道 + 平均旋转延迟 + 传输；平均旋转延迟 = 60/(2×rpm) 秒。

模板 5 · 文件索引与位示图

每块指针数 P = 块大小 ÷ 地址大小。
最大文件 = 直接项×块 + P×块 + P²×块 + P³×块（按题目启用的级数算）。
位示图：字号 = 块号 ÷ 字长，位号 = 块号 mod 字长；注意块号从 0 还是 1 开始。

模板 6 · 缓冲与 I/O 时间

单缓冲每块 = max(C,T) + M；双缓冲每块 = max(C+M,T)。
N 块总时间 = N × 每块时间（按题目是否给初始填充调整）。
中断次数 = 数据量 ÷ 每次中断传输量；DMA 中断次数 = 数据量 ÷ 每块大小。

5. PV 大题四步法（408 最高频大题）

找角色。把题目里的「谁」列成进程：生产者/消费者、读者/写者、司机/售票员、爸爸/儿子/女儿。每个角色一个 while(true) 循环。
找资源与约束。缓冲区容量 → empty/full；共享变量 → mutex；谁必须先于谁 → 同步信号量初值 0。
设信号量。资源信号量初值 = 可用数量；互斥信号量初值 = 1；同步信号量初值 = 0。给每个信号量写一句注释。
写代码并检查。每个 P 都有对应 V；资源 P 一定在互斥 P 之前；没有「持有 mutex 等资源」的路径；不会有两个进程同时进临界区。
📌 生产者-消费者满分骨架
semaphore empty = n, full = 0, mutex = 1;
Producer() {
    while (1) {
        produce(item);
        P(empty);  P(mutex);
        put(item);
        V(mutex);  V(full);
    }
}
Consumer() {
    while (1) {
        P(full);   P(mutex);
        item = get();
        V(mutex);  V(empty);
        consume(item);
    }
}
评分点通常包括：信号量初值、P/V 配对、P 的顺序、临界区范围。代码写错顺序，后面全扣，所以先检查顺序再写细节。

6. 错题本三栏法：不抄题，抄「触发条件」

栏写什么示例
① 题目定位章节 + 题号 + 一句话题干第 3 章 · 页面置换 · FIFO 3/4 页框
② 错因不是「粗心」，要具体到「哪个概念/哪一步」把「页框数增加」当成「缺页一定减少」，忘了 Belady
③ 正确触发条件下次看到什么词，就该用什么方法看到「FIFO + 页框数变化」→ 先想 Belady；看到「未来最晚」→ OPT

复习节奏：当天记 → 第 2 天重做 → 第 7 天重做 → 考前一周只翻第 ②③ 栏。错题本不是收藏夹，是「下一次不再错」的检查清单。本站练习场的「只看错题」就是电子版错题本，但建议你另外用纸笔写一遍错因。

7. 真题两遍法：第一遍学，第二遍考

第一遍 · 按章做

学完一章做对应真题，不限时，重点是「知道这章怎么考」。做错就回章节补，不追求分数。

第二遍 · 按套限时

考前 4~6 周开始，按套卷限时做 OS 部分（约 35 分钟），训练取舍与计算速度。做完只分析错题和不确定的题。

⚠️ 不要「看题背答案」
真题的价值在「命题角度」和「采分点」，不在原题。第二遍如果只是记住选项，换一道同型题还是错。每道错题都要能说出：考的是哪个机制、第一步该算什么、陷阱在哪。

8. 精确记忆清单（考前必须脱口而出）

进程与线程

  • 五状态：创建、就绪、运行、阻塞、终止；运行→阻塞主动，阻塞→就绪被动。
  • 进程切换四步：保存现场 → 更新 PCB/入队 → 选新进程 → 恢复现场/换页表。
  • 调度指标：周转 = 完成−到达；带权 = 周转/服务。
  • 临界区四原则：空闲让进、忙则等待、有限等待、让权等待。
  • 死锁四条件：互斥、不可剥夺、请求并保持、循环等待。

内存管理

  • 分页：页号 + 偏移；物理地址 = 页框 × 页大小 + 偏移。
  • 页表项数 = 2^页号位数；页表大小 = 项数 × 项大小。
  • 无 TLB：分页/分段 2 次访存；段页式 3 次。
  • 置换：OPT 最优不可实现；FIFO 有 Belady；LRU 近似最优；CLOCK 近似 LRU。
  • 抖动根因：页框 < 工作集，缺页率过高。

文件与磁盘

  • 连续：快、有外部碎片、难扩展；链接：灵活、隐式只能顺序；索引：随机访问、多占索引块。
  • 硬链接共享 inode；软链接存路径、可跨文件系统。
  • FAT 表项数 = 磁盘块数。
  • 混合索引：P = 块大小/地址大小；最大文件 = (d+P+P²+P³)×块大小。
  • 磁盘时间 = 寻道 + 旋转（平均半圈）+ 传输。

I/O 管理

  • CPU 干预频率：程序查询 > 中断 > DMA > 通道。
  • 中断每字节/字；DMA 每块；通道每组 I/O。
  • 层次：用户层 → 设备独立性 → 设备驱动 → 中断处理 → 硬件。
  • 单缓冲 max(C,T)+M；双缓冲 max(C+M,T)。
  • SPOOLing：磁盘输入井/输出井，把独占设备虚拟成共享设备。

9. 常见弃疗点与对策

弃疗点为什么卡对策
PV 操作看不懂把它当数学，没建立「资源 + 队列」的直觉先看本站动画和生产者-消费者代码，再用「先资源后互斥」检查；手写 5 遍骨架
多级页表算不清位数、项数、页大小混在一起固定三步：偏移位数 → 页号位数 → 每页项数；用 32 位/4KB/4B 反复练
银行家算法表太大，算到一半乱只写 Need=Max−Alloc；Work 表逐行更新；每次只找「Need ≤ Work」的进程，找到一个就划掉
磁盘调度图不知道 SCAN 到不到端点先看题目定义；默认按「实际移动」算；画横轴，标起点和请求点，按方向连线
英文缩写太多PCB/TCB/TLB/SPOOLing 混每个缩写写一张卡片：全称 + 一句话作用 + 一个例子；每天扫一遍
概念题总错只背结论，没理解「为什么」用「解决什么问题/没有会怎样/代价是什么」三问复述每个机制

10. 考场策略：先拿步骤分

选择题控制节奏。40 题 80 分，平均 1.5 分钟/题；OS 的 10 题控制在 15 分钟内，不会的先标记，别恋战。
大题先写公式。调度题先画时间轴，页面置换先画表格，地址转换先写位数，PV 先列信号量。公式和步骤本身就是采分点。
先做会做的。两道 OS 大题里，PV 和页表通常更容易拿分；磁盘/文件索引如果卡住，先写公式再算，别空着。
单位和小数。周转时间写 ms，缺页率写 %，文件大小写 MB/GB；最后检查一遍「页号从 0 还是 1 开始」。
留 5 分钟检查。重点查：PV 的 P 顺序、页表项数是否用了地址总位数、SCAN 是否漏算端点、缓冲公式是否漏 M。
