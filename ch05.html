5.1 先说人话：CPU 怎么指挥设备

🚚 生活类比
CPU 是老板，I/O 设备是外部仓库。老板不可能自己跑去仓库搬货，于是雇了一个仓库管理员（I/O 控制器）：老板只要往管理员的登记本上写「把第 3 号货架的第 2 箱搬到内存」，管理员负责指挥叉车（设备）干活，干完再按铃（中断）通知老板。这个登记本上的格子，就是控制器的寄存器。

I/O 设备分类：

分类角度类型例子特点
信息交换单位块设备 / 字符设备磁盘 / 键盘、打印机块设备可寻址、传输以块为单位；字符设备以字节流为单位，通常不可寻址
使用特性存储设备 / 人机交互设备 / 网络通信设备磁盘 / 键盘鼠标显示器 / 网卡传输速率与交互方式差异大
传输速率高速 / 中速 / 低速磁盘 / 打印机 / 键盘决定缓冲与调度策略

5.1.1 I/O 控制器与 I/O 端口

I/O 控制器是 CPU 与设备之间的桥梁，通常包含：数据寄存器（暂存传输数据）、控制寄存器（CPU 写入命令）、状态寄存器（设备状态，如忙/就绪/错误）、地址寄存器（DMA 时存放内存地址）。CPU 通过这些寄存器与设备交互，这些寄存器统称 I/O 端口。

端口映射 I/O（PMIO）

I/O 端口有独立的地址空间，CPU 用专门的 IN/OUT 指令访问。x86 传统方式。

内存映射 I/O（MMIO）

把设备寄存器映射到内存地址空间，CPU 用普通 load/store 指令访问，编程更方便。现代设备常用。

5.2 四种 I/O 方式：CPU 越来越省心

方式做法CPU 干预频率传输单位优点 / 缺点
程序查询CPU 循环读状态寄存器，设备就绪后由 CPU 搬数据最高（忙等）字/字节简单；CPU 大量空转，利用率低
中断驱动CPU 启动设备后去做别的；设备完成一个字节/字后发中断，CPU 来处理较高（每字节/字一次中断）字/字节CPU 不必忙等；中断频繁，开销大
DMADMA 控制器直接在设备与内存之间搬运一整块数据，结束时才中断 CPU低（每块一次）数据块CPU 干预少；DMA 控制器与 CPU 争内存总线

DMA 的三种工作方式

停止 CPU 访存：DMA 传输时 CPU 不能访存，简单但 CPU 停顿。周期挪用：DMA 每次抢一个总线周期，CPU 只被短暂延迟，最常用。交替访问：CPU 与 DMA 分时使用总线，效率高但硬件复杂。DMA 传输结束后通过中断通知 CPU。

5.3 I/O 软件层次：从上到下，越来越接近硬件

用户层 I/O 软件。库函数（如 printf/read）、SPOOLing 的用户接口。把用户请求转成系统调用。
设备独立性软件。统一命名（逻辑设备名 → 物理设备）、缓冲、缓存、SPOOLing、错误处理、设备保护。它让上层不必关心具体设备。
设备驱动程序。与硬件相关：把抽象 I/O 请求翻译成控制器寄存器的读写、启动设备、处理设备特有的时序。
中断处理程序。设备完成/出错时保存现场、处理中断、唤醒等待进程。
硬件。设备控制器与设备本身。
I/O 软件四层：谁管抽象、谁管硬件可视化
用户层 I/O 软件 库函数 printf/read · SPOOLing 用户接口
设备独立性软件 逻辑设备名 → 物理设备 · 缓冲 · 缓存 · SPOOLing · 保护
设备驱动程序 读写控制器寄存器 · 启动设备 · 设备特有操作
中断处理程序 保存现场 · 处理完成/错误 · 唤醒进程
硬件 I/O 控制器 + 设备
越往上越抽象、越与设备无关；越往下越接近硬件。设备独立性软件负责「叫什么名字」，设备驱动程序负责「怎么操作」。
📌 设备独立性软件 vs 设备驱动程序
设备独立性软件：与具体设备无关，负责「逻辑设备名 → 物理设备」映射（LUT 表）、缓冲、缓存、SPOOLing、权限检查。
设备驱动程序：与具体设备强相关，负责「怎么操作这台设备」——寄存器地址、命令字、时序。
选择题常问「哪一层负责逻辑设备名到物理设备名的映射」——设备独立性软件。

5.4 缓冲区：抹平 CPU 与设备的速度差

🧺 生活类比
设备像一辆一趟只能拉一箱货的小车，CPU 像一条流水线。没有缓冲区，流水线要停下来等小车；有了缓冲区，小车先把货卸到暂存区（缓冲区），流水线从暂存区取货，双方都能连续工作。缓冲区就是「以空间换时间」。

设：T = 设备把一块数据输入缓冲区的时间；M = 缓冲区数据传到用户区的时间；C = CPU 处理这块数据的时间。

单缓冲 每块平均处理时间 = max(C, T) + M
处理 n 块总时间 ≈ n × [max(C, T) + M]
双缓冲 每块平均处理时间 = max(C + M, T)
处理 n 块总时间 ≈ n × max(C + M, T)
🧮 例：T=100ms，C=80ms，M=50ms
单缓冲：max(80,100)+50 = 150ms/块；双缓冲：max(80+50,100) = 130ms/块。双缓冲让设备与 CPU 的重叠更好，但要多一块缓冲区。若 T 很小、C 很大，双缓冲的收益就不明显。

缓冲的类型

类型做法适用
单缓冲一块缓冲区，设备与 CPU 轮流用简单场景，速度差不大
双缓冲两块缓冲区，设备填一块时 CPU 处理另一块速度差较大，需连续传输
循环缓冲多个缓冲区组成环形队列，输入/输出指针移动连续、突发数据流
缓冲池系统维护空缓冲队列、输入队列、输出队列，按需取用多设备、多进程共享，最通用

缓冲 vs 缓存：缓冲（buffer）是为了「速度匹配」，存放的是传输中的临时数据；缓存（cache）是为了「减少访问」，存放的是数据的副本，可能重复使用。两者目的不同，别混。

5.5 设备分配：把设备借给谁

设备分配的数据结构有四张表：SDT（系统设备表，记录所有设备）、DCT（设备控制表，每台设备一张）、COCT（控制器控制表）、CHCT（通道控制表）。分配时从 SDT 找到设备，再逐级检查控制器、通道是否可用。

策略含义例子
独占设备一次只能分配给一个进程，直到释放打印机、磁带机
共享设备可同时分配给多个进程，交替使用磁盘（按扇区/块共享）
虚拟设备用 SPOOLing 把独占设备虚拟成共享设备打印机通过输出井共享

静态分配在作业开始前一次性分配所需设备，简单但利用率低；动态分配在需要时申请、用完释放，利用率高但可能死锁。分配时要考虑安全性，常用「按序分配」破坏循环等待。

5.6 SPOOLing：把一台打印机变成很多台

SPOOLing（假脱机）在磁盘上开辟输入井和输出井，用预输入程序把输入设备的数据提前读入输入井，用缓输出程序把输出井的数据慢慢写到设备。用户进程不再直接操作独占设备，而是读写井中的文件——于是独占设备被「虚拟」成共享设备。

用户进程要打印时，把输出内容写入磁盘的输出井，并登记一张打印请求表。
SPOOLing 系统为每个请求创建一个「虚拟打印机」，进程立刻认为打印完成，可以继续运行。
缓输出程序按队列顺序从输出井取数据，真正驱动打印机输出。
打印机是独占的，但多个进程可以「同时」提交打印任务，互不阻塞。
SPOOLing：一台打印机怎么被「分身」可视化
进程 P1打印请求
进程 P2打印请求
进程 P3打印请求
→
输出井磁盘上的排队文件
→
缓输出程序按队列顺序取
→
打印机独占设备，逐个打印
输入设备键盘/读卡机
→
输入井预输入程序提前读入
→
用户进程直接从输入井读
SPOOLing 需要磁盘（井）+ 通道（并行搬运）+ 中断（通知完成）。它把「独占设备」虚拟成「共享设备」，用户进程不用等慢设备。
📌 SPOOLing 的条件与代价
需要：磁盘（存放输入井/输出井）、通道（让数据搬运与 CPU 并行）、中断（通知完成）。
优点：把独占设备虚拟为共享设备，提高利用率；用户进程不必等待慢设备。
代价：占用磁盘空间；输出井满时仍会阻塞；实现比普通缓冲复杂。

5.7 磁盘缓存：内存里的「磁盘副本」

磁盘缓存把最近读过的磁盘块放在内存中，下次访问先查缓存。命中则直接返回，未命中再读磁盘。它和缓冲区不同：缓存是为了减少磁盘访问，缓冲区是为了匹配速度。

写回（write-back）

先写缓存，标记脏页，稍后再写磁盘。写快，但掉电可能丢数据。

写穿（write-through）

每次写都同时写缓存和磁盘。数据安全，但写性能差。

磁盘缓存的命中率受缓存容量、替换算法、访问局部性影响。缓存与磁盘调度配合：先看缓存是否命中，未命中才产生磁盘 I/O，再由调度算法决定磁头顺序。

🚀 进阶深挖（教材级）

深挖 1 · 一次 read 系统调用的完整路径

用户调用 read(fd, buf, n) → 系统调用进入内核 → 设备独立性软件检查参数、查缓存 → 缓存未命中则调用设备驱动程序 → 驱动程序写控制器寄存器启动 DMA → 进程阻塞，调度其他进程 → DMA 完成，设备发中断 → 中断处理程序唤醒进程 → 数据从内核缓冲区拷贝到用户 buf → 返回用户态。这条路径把本章所有概念串起来了。

深挖 2 · 中断驱动与 DMA 的 CPU 开销对比

假设传输 1MB 数据，每次中断处理 1KB：中断方式需要 1024 次中断；若每次中断开销 5μs，仅中断就 5.12ms。DMA 以 4KB 为一块，只需 256 次中断，开销降到 1.28ms，且数据搬运不占 CPU。块越大，CPU 干预越少，但 DMA 占用总线时间越长，响应延迟可能变大。

深挖 3 · 缓冲池怎么工作

缓冲池由三类队列组成：空缓冲队列（可用缓冲区）、输入队列（装满输入数据待处理）、输出队列（装满输出数据待写出）。进程需要输入时，从空队列取一个缓冲，填入数据后挂到输入队列；需要输出时，从空队列取一个，填入数据后挂到输出队列。缓冲区在队列之间移动，实现多设备、多进程共享。

深挖 4 · I/O 与虚拟内存的交叉

DMA 需要访问的内存页必须常驻且物理地址固定，否则传输到一半页面被换出会出错。OS 通常把 DMA 缓冲区「钉住」（pin）在内存中，或使用物理地址连续的缓冲区。这也是为什么高性能 I/O 常用「零拷贝」：减少用户态/内核态之间的数据拷贝，让数据直接从磁盘页缓存送到网卡。

📝 章内练习（16 题 · 基础 → 提高 → 真题改编）

🟢 第一档 · 基础（4 题）

基础练习 1 · 考点：设备分类
下列设备中，属于字符设备的是：
A. 磁盘
B. 键盘
C. 光盘
D. 固态硬盘
解析：选 B。键盘以字节流方式输入，通常不可寻址，属于字符设备。磁盘、光盘、SSD 都以数据块为单位存取，属于块设备。
基础练习 2 · 考点：I/O 控制器
I/O 控制器中，CPU 用来读取设备状态（忙/就绪/错误）的部件是：
A. 数据寄存器
B. 控制寄存器
C. 状态寄存器
D. 地址寄存器
解析：选 C。状态寄存器保存设备当前状态（忙、就绪、错误等）；数据寄存器暂存传输数据；控制寄存器接收 CPU 命令；地址寄存器在 DMA 时保存内存地址。
基础练习 3 · 考点：程序查询
程序查询方式的主要缺点是：
A. CPU 忙等设备状态，利用率低
B. 每次传输都要 DMA 控制器参与
C. 只能用于块设备
D. 不需要设备驱动程序
解析：选 A。程序查询由 CPU 循环读取状态寄存器，设备没就绪就一直空转，CPU 无法做别的事。B 是 DMA 的特点；C 错，字符设备也能查询；D 错，任何 I/O 都需要驱动/控制逻辑。
基础练习 4 · 考点：DMA
DMA 方式下，CPU 通常在什么时候被中断？
A. 每传输一个字节中断一次
B. 每传输一个字中断一次
C. 设备启动时中断一次
D. 一整块数据传输完成后中断一次
解析：选 D。DMA 控制器负责在设备与内存之间搬运整块数据，CPU 只在传输开始前设置参数、传输结束后处理中断。A、B 是中断驱动方式；C 错，启动时是 CPU 写寄存器，不是中断。

🟡 第二档 · 提高（4 题）

提高练习 5 · 考点：通道
与 DMA 相比，通道的主要优势是：
A. 不需要中断
B. 能执行通道程序，独立控制多台设备完成一组 I/O，进一步减少 CPU 干预
C. 传输速度一定比 DMA 慢
D. 只能连接字符设备
解析：选 B。通道是一个专用的 I/O 处理器，能执行通道程序，控制多台设备完成一组 I/O，CPU 只需在开始时启动、结束时处理中断。A 错，通道完成时仍用中断通知；C 错，通道通常更强；D 错，通道可连接块设备和字符设备。
提高练习 6 · 考点：I/O 软件层次
负责「逻辑设备名到物理设备名映射」的是：
A. 用户层 I/O 软件
B. 设备驱动程序
C. 设备独立性软件
D. 中断处理程序
解析：选 C。设备独立性软件通过逻辑设备表（LUT）把用户使用的逻辑设备名映射到物理设备，并负责缓冲、缓存、SPOOLing、保护等。设备驱动程序负责具体硬件操作；用户层只是库函数；中断处理负责完成通知。
提高练习 7 · 考点：单缓冲计算
T=100ms，M=50ms，C=80ms，采用单缓冲，每块数据的平均处理时间是：
A. 150ms
B. 130ms
C. 100ms
D. 230ms
解析：选 A。单缓冲：max(C,T)+M = max(80,100)+50 = 100+50 = 150ms。B 是双缓冲的结果 max(80+50,100)=130ms；C 漏了 M；D 把三个量直接相加。
提高练习 8 · 考点：双缓冲计算
T=100ms，M=50ms，C=80ms，采用双缓冲，每块数据的平均处理时间是：
A. 150ms
B. 130ms
C. 100ms
D. 180ms
解析：选 B。双缓冲：max(C+M,T) = max(80+50,100) = 130ms。双缓冲让设备填一块时 CPU 处理另一块，所以比单缓冲的 150ms 快；但若 T 远大于 C+M，瓶颈仍在设备，双缓冲也帮不上。

🔴 第三档 · 真题改编（8 题 · 题型对标）

真题改编2012 题型练习 9 · 考点：中断驱动
中断驱动 I/O 方式中，CPU 的干预频率通常是：
A. 每个数据块一次
B. 每组 I/O 一次
C. 从不需要干预
D. 每传输一个字节/字一次
解析：选 D。中断驱动方式下，设备每完成一个字节/字的传输就发一次中断，CPU 中断频繁、开销大。A 是 DMA；B 是通道；C 任何 I/O 都需要 CPU 至少启动和收尾。
真题改编2014 题型练习 10 · 考点：SPOOLing
SPOOLing 技术的主要作用是：
A. 提高 CPU 主频
B. 把独占设备虚拟成共享设备，提高设备利用率
C. 减少磁盘容量占用
D. 替代所有内存缓冲
解析：选 B。SPOOLing 用磁盘上的输入井/输出井 + 预输入/缓输出程序，让多个进程「同时」使用一台独占设备（如打印机），把独占设备虚拟成共享设备。它不提高主频、反而占磁盘，也不能替代内存缓冲。
真题改编2016 题型练习 11 · 考点：缓冲 vs 缓存
下列关于缓冲（buffer）与缓存（cache）的说法，正确的是：
A. 两者目的相同，都是减少磁盘访问
B. 缓冲存放数据副本，缓存存放传输中的临时数据
C. 缓冲主要用于匹配速度，缓存主要用于减少重复访问
D. 缓存一定在磁盘上，缓冲一定在内存中
解析：选 C。缓冲解决 CPU 与设备速度不匹配，存放传输中的临时数据；缓存存放数据副本，减少对慢速存储的重复访问。B 说反了；A 混淆目的；D 错，缓存也可以在内存/CPU 中。
真题改编2018 题型练习 12 · 考点：DMA 中断次数
传输 1MB 数据，DMA 每次传输 4KB 块，传输完成后中断一次。整个传输过程中 CPU 被中断的次数约为：
A. 256 次
B. 1024 次
C. 1 次
D. 4096 次
解析：选 A。1MB / 4KB = 256 块，每块完成中断一次，共 256 次。B 是每次中断传 1KB 的中断驱动方式；C 是通道方式完成一整组 I/O 才中断一次；D 是每次传 256B 的情况。
真题改编2013 题型练习 13 · 考点：设备分配表
设备分配中，记录系统中所有设备情况的总表是：
A. DCT（设备控制表）
B. COCT（控制器控制表）
C. CHCT（通道控制表）
D. SDT（系统设备表）
解析：选 D。SDT 是整个系统的设备总表，每个表项指向一台设备的 DCT；DCT 记录单台设备状态，COCT 记录控制器，CHCT 记录通道。分配时从 SDT 出发逐级检查。
真题改编2015 题型练习 14 · 考点：虚拟设备
下列设备中，通常通过 SPOOLing 被虚拟成共享设备的是：
A. 磁盘
B. 打印机
C. 内存
D. CPU
解析：选 B。打印机是典型的独占设备，SPOOLing 用输出井把多个打印任务排队，让每个进程都以为自己独占打印机。磁盘本来就是共享设备；内存和 CPU 不是 I/O 设备。
真题改编2019 题型练习 15 · 考点：磁盘缓存写策略
磁盘缓存采用写回（write-back）策略时，下列说法正确的是：
A. 每次写都同时写磁盘，数据最安全
B. 写缓存后立即丢弃，不写磁盘
C. 先写缓存并标记脏页，稍后再写磁盘；掉电可能丢失未写回数据
D. 只适用于只读文件
解析：选 C。写回策略先写缓存、标记脏页，延迟写磁盘，写性能好，但掉电可能丢数据。A 是写穿；B 不是正常策略；D 错，写回用于可写数据。
真题改编2021 题型练习 16 · 考点：I/O 方式综合
下列四种 I/O 方式中，CPU 干预频率从高到低排列正确的是：
A. 程序查询 > 中断驱动 > DMA > 通道
B. 通道 > DMA > 中断驱动 > 程序查询
C. 中断驱动 > 程序查询 > 通道 > DMA
D. DMA > 通道 > 程序查询 > 中断驱动
解析：选 A。程序查询 CPU 一直忙等；中断驱动每字节/字中断；DMA 每块中断；通道每组 I/O 才中断。干预频率依次降低。记住「查询 > 中断 > DMA > 通道」。
